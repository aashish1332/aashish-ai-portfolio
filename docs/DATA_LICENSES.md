# DATA LICENSES — what is in the corpus, and what may enter it

§7.3 requires every data source to be licence-checked and recorded **before**
it is used. This file is that record. Nothing here is aspirational: a source
listed under "candidates" has not been downloaded, and the pipeline refuses
to run on anything not listed under "in use".

## In use today (P3 dev fixture)

| Source | What | Licence / provenance | Status |
|---|---|---|---|
| `training/scripts/make_seed_corpus.py` | 17,402 lines / 3.2 MB: English conversation and simple prose, Devanagari Hindi, Roman Hinglish, tech/code fragments, URL syntax, copy-from-context passages | **Ours.** Every line is either hand-written in the generator or assembled from hand-written slot lists. No third-party text, no scraped text, no LLM-generated text | in use |
| `knowledge/knowledge.json` | fact values used to exercise the PII-to-placeholder rule | The portfolio owner's own published CV/portfolio content | in use (values replaced by placeholder tokens in the corpus) |

Generated by `python -m training.scripts.make_seed_corpus`; regenerable bit
for bit (fixed RNG seed `20260920`), so it can be audited line by line.

**What it is not:** it is not the Stage A corpus, it is not representative of
web text, and no quality claim about the model may rest on it. It exists so
the pipeline, tokenizer, checkpointing and resume logic can be exercised
offline.

### Filters applied to it

| Filter | Implementation | Honest limitation |
|---|---|---|
| PII | `ai/data/pipeline.py::mask_pii` — public facts → placeholder tokens, emails/phones removed, unknown-host URLs removed, query strings stripped, 7+ digit runs removed | pattern-based, not an NER model |
| Toxicity | 6-word blocklist | **not a classifier.** P4 replaces it with a real filter and records what it missed |
| Dedupe | exact SHA-1 + 4-word-shingle Jaccard ≥ 0.8, bucketed by min shingle hash | threshold measured, not guessed (see `NEAR_DUP_THRESHOLD`) |
| Language ID | `ai/data/langid.py`, a port of the runtime detector, pinned by a 49-case cross-runtime fixture | rule-based; Roman Hinglish with no function words reads as weak English, by design |
| Length / letters / emptiness | `filter_reasons` | — |

## Candidates for P4 Stage A — **not downloaded, not used**

Each one must be licence-verified, PII-filtered, and recorded here with its
version, retrieval date, licence text and the filters applied, *before* a
single line enters `data/raw/`. If a licence check fails, the source is
dropped and the reason recorded.

| Candidate | Intended use | Open questions to settle first |
|---|---|---|
| AI4Bharat **Sangraha** (verified subset) | Hindi (Devanagari) | licence terms for the verified subset, and how to reproduce the subset without the whole collection |
| **Hindi Wikipedia** | Hindi prose | CC BY-SA attribution obligations for a trained model; dump date and revision pinning |
| **L3Cube-HingCorpus** | real Roman code-mixed Hinglish | Twitter-derived: PII, toxicity and URL filtering required; licence check mandatory; conversational noise may be too high for a narrow, clean distribution |
| Curated simple English / dialogue corpora | Stage A English | licence per corpus; must be *simple and clean*, not a web dump (§7.3) |
| Programmatic Hinglish | volume, controlled vocabulary | must be labelled synthetic in any dataset card; not a substitute for human-written code-mixing |
| Portfolio-derived instruction data | Stage B (§7.4), P5 | ours, generated from `knowledge.json`; no external licence |

### Rules that apply to whatever is chosen

1. **No third-party LLM-generated dataset** unless its provenance is recorded
   and disclosed in the dataset card and in this file.
2. **No text sourced from the CV beyond what the portfolio already
   publishes** (`public:true`), and never the withheld phone number.
3. `data/raw/`, `data/processed/` and checkpoints stay out of the repository
   (§17), so no licensed third-party text or personal data is redistributed
   with this project.
4. Every dataset version is pinned by hash in `training/RUN_MANIFEST.json`
   and in the shard manifest, so a trained model can be traced to the exact
   lines it saw.
